# Proyecto de Página Web Responsiva

## Descripción

Este proyecto es una página web responsiva diseñada para adaptarse a diferentes tamaños de pantalla, utilizando un enfoque `mobile first`. El sitio incluye una serie de elementos interactivos y visuales, como imágenes, descripciones y botones, que se ajustan según el dispositivo utilizado para garantizar una experiencia de usuario fluida tanto en dispositivos móviles como en escritorios.

### Características:
- **Diseño Mobile First**: La página se adapta de manera eficiente a pantallas pequeñas, con una transición fluida hacia escritorios.
- **Interactividad**: El botón "Read more" permite expandir y contraer texto en una interfaz limpia y accesible.
- **Efectos visuales**: La página incluye efectos de difuminado y superposiciones con imágenes que mejoran la experiencia visual.
- **Responsive**: Utiliza `media queries` para ajustar los estilos en función del tamaño de la pantalla, manteniendo la funcionalidad y estética de la página en todo momento.

## Tecnologías empleadas

- **HTML5**: Estructura semántica del contenido.
- **CSS3**: Estilización, incluyendo Flexbox, Grid y `media queries` para la adaptabilidad.
- **Google Fonts**: Uso de la fuente "Inter" para una tipografía moderna y legible.
- **Backdrop-filter**: Para aplicar efectos de difuminado a los fondos y darle un toque más visual a los botones.
